🍪 导出爱豆糖 SSO Cookie 工具

⚠️ 仅在你自己信任的设备上使用。Cookie 等同于登录态,泄漏后别人能冒充你访问爱豆糖。

📋 步骤 1:登录爱豆糖

  1. 在 Chrome 浏览器(推荐)中打开 https://xwv5.aidoutang.com/dwpush/
  2. 正常登录 SSO(走完图形验证码),确认能看到推送列表
  3. 保持这个浏览器标签页打开,不要关闭

📋 步骤 2:导出 Cookie

方法 A:Console 一键导出(最快,推荐 ⭐)

① 关键:先把标签页切换到 https://dw.aidoutang.com/(直接地址栏输入回车即可,会自动跳转)

② 在该标签页按 F12 → 切到 Console 标签

③ 粘贴下面这行,按回车:

navigator.clipboard.writeText(document.cookie).then(() => alert('Cookie 已复制到剪贴板!\n长度: ' + document.cookie.length + ' 字符\n直接粘贴到 GitHub Secret 即可'));

④ 弹窗说已复制,直接到 GitHub → Settings → Secrets → New secret → Name: AIDOUTANG_COOKIE → Value 粘贴

方法 B:DevTools 手动复制

① 切换到 https://dw.aidoutang.com/ 域的页面

② 按 F12 → 切到 Application 标签 → 左侧 Storage → Cookies → https://dw.aidoutang.com

③ 右侧会列出所有 Cookie。手动拼接成 name1=value1; name2=value2; ... 的形式

④ 或者在 Console 跑 document.cookie,把输出整行复制

📋 步骤 3:在 GitHub 配置两个 Secret

  1. 打开 仓库的 Secrets 页面
  2. 点击 New repository secret,添加两个:
    • AIDOUTANG_COOKIE = 第 2 步复制的整串(类似 SESSION=abc123; token=xyz789; userId=...)
    • PUSH_TASK_ID = 3084(你之前发的 URL 里的 id 值)

✅ 验证 Cookie 是否有效

在终端/命令行运行(替换 YOUR_COOKIE 为你导出的字符串):

curl -H "Cookie: YOUR_COOKIE" \
     https://dw.aidoutang.com/pushservice/api/checkLogin

如果返回 {"code":0,...} 就 OK;如果返回 {"code":10020,"msg":"未登录"} 说明 Cookie 失效,重新导出。

Cookie 通常有效期 7-30 天。失效后 GitHub Actions 会失败提醒你,届时重新导出一次即可(大约 30 秒搞定)。
